# ADR：<决定标题>

使用本模板记录一个经用户确认的长期架构决定，并删除所有占位说明。

- 状态：Proposed
- 日期：YYYY-MM-DD
- 决策人：<团队或角色>
- 相关 change：`<change-id>`
- Supersedes：无
- Superseded by：无

## Context

说明需要决定的问题、约束和触发 ADR 的长期影响信号。只写理解决定所需的事实。

## Decision

明确记录选择的方案、适用边界和不包含的范围。

## Consequences

列出采用该决定后的正面结果、成本、风险和后续义务。

## Alternatives

列出认真评估过的替代方案及未采用原因。
