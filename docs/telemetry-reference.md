This generated reference is the public Repoctopus OTLP contract. Change the machine catalog in `domains/telemetry/observation-contract.ts`, then run `npm run generate:telemetry-reference`. Do not edit this file by hand.

Field names are protocol, not deployment configuration. Configure the Collector address and authentication with standard OpenTelemetry environment variables; build SigNoz dashboards against the names below.

## Out-of-scope providers

The 13 out-of-scope metrics require evidence owned by another system: RAG evaluation sets, answer and fact evaluation, IDE completion and code attribution, identity directories, Rule-edit audit, or training and certification records. Add one only through a reviewed Provider that supplies durable identity, provenance, privacy bounds, and missing-data semantics. Repoctopus must not infer these metrics from workflow success.

## SigNoz query rules

- Skill completion rate: divide `repoctopus.skill.usage{result=completed}` by `repoctopus.skill.usage{result=consumed}` in the same window and role/category group.
- Human correction rate: divide `result=corrected` by `result=consumed`.
- Skill error rate: divide `result=error` by `result=consumed`.
- Skill reuse rate: query `repoctopus.measurement.skill`, deduplicate by measurement ID, group consumed facts by exact Skill ID, then divide identities used more than once by all consumed identities.
- Rule hit rate: divide `repoctopus.rule.evaluation{result=triggered}` by `result=expected`.
- Rule violation rate: divide `result=violated` by evaluated receipts; do not include rules without a receipt.
- Workflow failure rate: divide terminal `result=failed` Runs by terminal completed plus failed Runs after deduplicating measurement IDs.
- Workflow reuse count: count `result=started` by workflow name and version after deduplicating measurement IDs.
- Efficiency improvement: compare terminal `repoctopus.workflow.run.duration` distributions for the same workflow name/version and an explicit baseline window. With no compatible baseline, report `unknown`.

Never group Metrics by Run, Work, invocation, Skill ID, Rule ID, receipt, path, or free text. Use measurement logs to drill into those identities. Do not add field aliases, Collector Transform renames, or credentials to Resource attributes.
