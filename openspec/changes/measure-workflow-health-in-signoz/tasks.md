# 工作流健康指标实施任务

## 1. Runtime 统计事实

- [ ] 1.1 核对 Run 启动、已批准 Build 策略和终态的权威来源，补齐规范观测及稳定身份。验收：换进程恢复、重复批准和导出重放后，同一 Run 只计一次。
- [ ] 1.2 投影当前阶段、状态、等待或阻塞原因与阶段进入时间。验收：等待审批、阻塞、恢复和未知原因都能从 OTLP 还原。
- [ ] 1.3 从状态机投影所有跨阶段回退及原目标阶段。验收：覆盖现有六条路径、连续回退、同阶段重试和零回退，重放无重复计数。

## 2. 远端降噪与投递

- [ ] 2.1 定义默认远端事实及按需诊断，按有限大小和时间合批。验收：短生命周期进程或恢复后仍能投递关键事实，桌面实时视图保留。
- [ ] 2.2 按目的地与信号跟踪投递进度，处理旧积压、部分拒收与明确失败。验收：Log 成功、Metric 失败后不会重发已确认的 Log；重复送达对看板计数无影响。

## 3. SigNoz 看板与验收

- [ ] 3.1 交付可导入看板及字段、查询、窗口和下钻说明。验收：四项指标可重复查询，跨窗口和空分母口径正确。
- [ ] 3.2 用真实多仓 Run 与本地 SigNoz MCP 对账。验收：覆盖完成、终态失败、等待、阻塞和不同回退路径，统计值与 Runtime 记录一致。
- [ ] 3.3 用同一多仓场景比较降噪前后的 HTTP 请求数、入库记录数和重复记录数。验收：记录测量范围、数据、失败恢复和桌面回归结果。
