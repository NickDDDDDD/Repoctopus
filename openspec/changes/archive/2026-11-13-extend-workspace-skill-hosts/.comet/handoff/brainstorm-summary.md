# Design 候选摘要

- 已确认范围来自 Open 批准的 proposal、两份 delta spec 和 5 项任务。
- 候选方案使用同一份入口正文及项目和个人路径映射。新增宿主显式选择。已接入 Workspace 的补装审批仅授权所选入口。
- TRAE 两个发行版的真实扫描行为、CodeArts 的启用状态与 CodeBuddy 可用验收客户端需要实测。
- 独立可实施性审查提出的两个边界已补入设计。逐一明确 Windows 必测客户端，记录现有 Run 与冻结 Evidence 的正常漂移边界。补装审批摘要核对只允许入口操作。
- 详细候选和验收范围见同一 Change 的 design.md。本轮沿用当前 OpenSpec delta spec。
